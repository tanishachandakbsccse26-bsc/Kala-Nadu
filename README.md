# Kala-Nadu

The Land of Art. Our Roots. Our Karnataka.

KALA NADU is a website celebrating Karnataka's rich cultural heritage, traditional art forms, festivals, food, lifestyle and hidden destinations.

Features of the Website

- Home: Introduction to Karnataka.
- Art & Traditions: Traditional art forms and handicrafts.
- Culture & Lifestyle: Festivals, clothing, food and languages.
- Hidden Karnataka: Lesser-known destinations.
- Quiz: Interactive Karnataka quiz.
- Feedback: Visitors can share their suggestions.
- Thank You: Displays a thank-you message and visitor feedback records.

Technologies Used

HTML, CSS, JavaScript, PHP, MySQL and XAMPP.

PHP and MySQL Integration

The website uses PHP and MySQL to store and display visitor feedback.

- XAMPP was used on macOS to run Apache and MySQL.
- Manager-OSX was used to manage the services.
- A database and feedback table were created using phpMyAdmin.
- PHP MySQLi was used to connect to the database.
- Submitted feedback is stored in MySQL and displayed on the Thank You page.

Project Setup

- Project files were placed inside the "htdocs" folder of XAMPP.
- Apache and MySQL were started using Manager-OSX.
- The website was accessed through "http://localhost/".
- phpMyAdmin was accessed through "http://localhost/phpmyadmin/".

Project Objective

To promote awareness of Karnataka's heritage and culture through an informative and interactive website.
